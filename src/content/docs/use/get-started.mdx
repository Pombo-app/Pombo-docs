Pombo runs in the browser and on Android. One account works on both.

## Get the app

| Where | How |
| --- | --- |
| Browser | Open [app.pombo.cc](https://app.pombo.cc). To install it as an app, use the install icon in the address bar, or **Install Pombo** in the browser menu. |
| Android | Download the APK from [GitHub Releases](https://github.com/Pombo-app/Pombo-Android/releases/latest). Each release has a `.sha256` file to check it against. Android 8.0 or newer. |
| iPhone, iPad | Open app.pombo.cc in Safari, tap **Share**, then **Add to Home Screen**. |

## Look around first

Pombo opens as **Guest**, with a throwaway key. You can browse Explore and read and write in Open channels. To keep your channels, create your own or send direct messages, create an account.

## Create an account

<Tabs syncKey="client">
<TabItem label="Web">
<Steps>

1. Press **Create Account**, then **Create New Account**.
2. Choose an avatar.
3. Set a password: at least 12 characters, with an uppercase letter, a lowercase letter and a number. It unlocks the account in this browser.
4. Save the private key shown, then press **Create Account**.

</Steps>
</TabItem>
<TabItem label="Android">
<Steps>

1. Press **Create Account**, then **Create New Account**.
2. Choose an avatar.
3. Save the private key shown, then press **Create Account**.

</Steps>

There is no password. Revealing the key, switching accounts or deleting one asks for your screen lock.
</TabItem>
</Tabs>

<Aside type="caution">
Your private key is your account. No server can recover it: keep it offline, or keep a [backup](/use/backup/).
</Aside>

## Already have an account

- **Import Private Key**, on the **Connect Account** screen, brings in an existing key.
- **restore**, on the same screen, opens a backup file. See [Backup and devices](/use/backup/).

## Join a channel

**Explore** lists public channels. Filter them by **Open**, **Gated** or **Paid**, and by category. Open one to see it, then press **Join**. More in [Channels](/use/channels/).

Reading and writing are free. Creating a channel or your DM inbox, and paying for a subscription, cost POL: see [Your account](/use/account/).
