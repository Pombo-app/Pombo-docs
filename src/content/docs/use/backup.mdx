## Export a backup

**Settings › Account › Backup & Restore › Export**. The web app encrypts the file with your account password; Android asks you to choose one, at least 8 characters. Either file restores on the web or on Android.

| In the backup | Not in the backup |
| --- | --- |
| Your key, encrypted | Messages and files you received: they come back from storage while it keeps them |
| Your channels, with their passwords and keys | Content settings |
| Direct messages and reactions you sent | |
| Blocked users, trusted contacts, display name, The Graph key | |
| Images you sent in DMs, unless you untick **Include sent DM media** | |

## Restore

<Steps>

1. On the **Connect Account** screen, press **restore**.
2. Pick the backup file and enter its password.

</Steps>

Already signed in? Use **Backup & Restore › Import**.

## Device sync

Devices of one account share channels, channel keys, sent direct messages and reactions, blocked users, contacts, ENS names, The Graph key and profile. Content settings stay on each device. Sync travels through your own DM inbox, so create it first.

| Mode | Syncs |
| --- | --- |
| **Automatic** | At start, when you come back to the app, and after each change |
| **Skip on start** | Like Automatic, without the run at start |
| **Manual only** | Only when you press **Sync Now** |

The mode is in **Settings › Device Sync** on both clients. **Sync Now** is in the account menu on the web, and in **Device Sync** on both clients.

<Aside title="A new device">
Import your key or restore a backup, then press **Sync Now** to bring in what changed since.
</Aside>
