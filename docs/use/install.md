# Install

## Web, any platform

Pombo runs in your browser at **[app.pombo.cc](https://app.pombo.cc)**. Nothing to download.

Installing it as an app gives you an icon, a full-screen UI and, on iOS, push notifications:

- **Chrome or Edge**, desktop and Android: the install icon in the address bar, or *Menu → Install app*.
- **Safari**, iOS 16.4+: *Share → Add to Home Screen*. Push on iOS works only for installed PWAs.

## Android

A native Kotlin app running the same protocol stack, from the [GitHub repository](https://github.com/Pombo-app/Pombo-Android). Same account format, same channels, same encryption as the web app, with Firebase Cloud Messaging for push.

Requires Android 8.0 (API 26) or newer.
